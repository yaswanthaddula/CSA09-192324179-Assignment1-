# Task 5 – Static Members and Object Lifecycle

## Aim
To understand static variables, static methods, ticket counters, and object lifecycle in Java.

## 1. Static Members

A static variable belongs to the class rather than an individual object. It is shared by all objects of that class.

Example:

```java
class ParkingTicket {
    private static int ticketCounter = 0;
    private final int ticketId;

    public ParkingTicket() {
        ticketId = ++ticketCounter;
    }

    public int getTicketId() {
        return ticketId;
    }

    public static int getTicketCounter() {
        return ticketCounter;
    }
}
```

## 2. Ticket Counter

Every time a new `ParkingTicket` object is created, the static counter increases by one. Each ticket receives a unique ID during the program's execution.

## 3. Object Lifecycle

1. An object is created using the `new` keyword.
2. Memory is allocated for the object.
3. The constructor initializes the object.
4. The object is used by the program.
5. When the object is no longer reachable, it may be garbage-collected by the JVM.

## 4. Alternative Approach

A ticket ID could be generated by an external ticket-management class. This separates ticket creation from ticket details but introduces an additional class and coordination.

## 5. Complexity Analysis

- Ticket creation: O(1) time.
- Reading the ticket ID: O(1) time.
- Reading the static counter: O(1) time.
- Each ticket object requires O(1) space.

## Conclusion

Static members are useful for maintaining a shared ticket counter. The counter assigns ticket IDs as objects are created, while garbage collection manages unreachable objects.
